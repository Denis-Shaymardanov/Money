Выбор способа синхронизации


Выберите удобный способ синхронизации данных между своими приложениями, или отключите синхронизацию, переведя это приложение в автономный режим работы

  • Автоматическая синхронизация через сервис - включает автоматическую синхронизацию данных с облачным сервисом 1С:Деньги. 
    Этот способ синхронизации позволяет синхронизировать данные между мобильными приложениями Миниденьги и настольными программами в любом сочетании.
  • Обмен файлами с мобильными устройствами - включает синхронизацию этой информационной базы с мобильными устройствами через выбранное вами облачное хранилище файлов или в домашней сети через wi-fi. В этом варианте настольная программа выступает в качестве центрального хранилища данных для мобильных устройств, а обмен данными выполняется только по команде пользователя.
  • Автономная работа - отключает синхронизацию и переводит эту информационную базу в автономный режим работы
