Управление облачным сервисом 1С:Деньги


Облачный сервис 1С:Деньги расширяет возможности мобильного приложения Миниденьги и настольной программы 1С:Деньги 8, автоматизируя и упрощая часть рутинных операций.

Учетная запись абонента

В самом верхнем разделе выводится информация об абоненте облачного сервиса:
  • Почтовый адрес - логин, используемый для подключения к учетной записи абонента.
    Нажмите ссылку Настройки подключения для изменения имени базы или пароля
  • Доступно лицензий - количество лицензий, активных на текущий день.
    Нажмите ссылку Активные подписки для просмотра списка действующих лицензий и их продления
  • Подключено баз - количество информационных баз, подключенных к учетной записи в облачном сервисе.
    Нажмите ссылку Список баз для просмотра информационных баз, отключения устаревших баз или запрета на соединение для потерянных устройств
Для того, чтобы услуги сервиса были доступны в полном объеме, количество подключенных информационных баз не должно превышать количество активных лицензий. При недостатке лицензий вы сможете только скачать информацию из облачного сервиса. Отправить в него изменения и использовать другие его возможности не получится.
Для продления подписки или приобретения новой нажмите на соответствующую кнопку ниже.

Результаты синхронизации

В этом разделе указывается информация о последней синхронизации данных и отображается текущее состояние синхронизации.
Выполняющуюся синхронизацию можно остановить нажатием на символ Х рядом с описанием ее состояния
  • нажмите ссылку События получения чтобы посмотреть записи журнала регистрации по последнему получению данных с сервера
  • нажмите ссылку События отправки чтобы посмотреть записи журнала регистрации по последней отправке данных на сервер
  • нажмите ссылку Итоги для просмотра результатов и других характеристик обмена данными

Параметры следующей синхронизации

В этом разделе можно задать параметры для следующей синхронизации данных с облачным сервисом. 
  • выберите нужный Способ синхронизации
    • Автоматически - синхронизация будет выполняться в автоматическом режиме
    • Вручную - синхронизация будет выполнена только по команде пользователя. Включите этот способ перед тем, как выполнить какие-то массовые изменения данных: переименование справочников, переделку операций и т.п.
  • Выберите Сценарий синхронизации данных
    • Синхронизировать изменения - это основной сценарий работы с данными, при котором изменения из этой информационной базы выгружаются на сервер, а с сервера получаются изменения, зарегистрированные там
    • Облако очистить и заполнить из этой базы - используйте для того, чтобы заменить все данные в облаке данными из этой базы. Будьте осторожны: удаленные таким образом данные восстановить невозможно!
    • Эту базу очистить и заполнить из облака - используйте чтобы заменить все записи этой базы данными из облака. Будьте осторожны и лучше сделайте резервную копию этой базы перед использованием такого сценария
  • Нажмите ссылку Отправляемые данные для просмотра списка зарегистрированных к отправке объектов. Чтобы зарегистрировать к отправке все объекты в этой базе нажмите кнопку Отметить все в строке К отправке
  • Посмотреть список помеченных к отправке объектов на сервере пока невозможно. А чтобы пометить все объекты в облачном сервисе к загрузке в эту базу нажмите кнопку Отметить все в строке К загрузке
Нажмите кнопку Синхронизировать сейчас для выполнения синхронизации с заданными параметрами.
