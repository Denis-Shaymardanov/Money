Политика конфиденциальности облачного сервиса 1С:Деньги


  1. Для регистрации в облачном сервисе 1С:Деньги требуется адрес электронной почты. Этот адрес используется как логин, его существование не проверяется. Никакой другой информации о пользователе не требуется
  2. Работа с облачным сервисом возможна только из мобильных приложений Миниденьги и из настольных программ 1С:Деньги 8 по защищенному соединению через сеть Интернет, при указании правильных логина и пароля. Другого доступа к данным в облачном сервисе не предусмотрено
  3. Сохранность логина и пароля от учетной записи в облачном сервисе обеспечивает только сам пользователь. Никто, кроме самого пользователя, не может отвечать за последствия забывания логина и пароля, их потери или кражи у пользователя
  4. Облачный сервис 1С:Деньги используется:
  • для хранения данных из приложений Миниденьги и 1С:Деньги 8
  • для синхронизации изменений между указанными приложениями
  • для автоматизации учета расходов и других действий прикладного уровня
  • Облачный сервис 1С:Деньги не анализирует хранящиеся в нем данные и не предоставляет их третьим лицам
  • Обращения к сторонним сервисам, которые могут потребоваться для автоматизации прикладных задач, выполняются облачным сервисом 1С:Деньги только в соответствии с заданными им настройками
