# Архитектура Money

Проект состоит из трёх связанных частей:

- `app/` — Python/FastAPI-сервис для обработки банковских выписок и чеков.
- `AccountingOfGoods/` — расширение конфигурации 1С.
- `BaseConfiguration/Money_2_0/` — выгрузка основной конфигурации 1С «Деньги».

Расширение и основная конфигурация хранятся в одном репозитории для общего контекста Codex, но остаются разными конфигурационными сущностями. Изменения основной конфигурации не следует автоматически переносить в расширение: совместимость нужно проверять в конфигураторе.

Python-сервис вызывается из расширения через серверные общие модули и настройки, описанные в исходниках 1С. Локальные адреса, токены и другие окруженческие параметры не являются частью репозитория.
