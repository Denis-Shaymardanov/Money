# Разработка

## Python

Из корня проекта:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Сервис запускается на `127.0.0.1:8000`. Логи и временные файлы не коммитятся.

## 1С

- Основная конфигурация: `BaseConfiguration\Money_2_0`.
- Расширение: `AccountingOfGoods`.
- Изменения расширения выполняются в конфигураторе или через VS Code с последующей проверкой в конфигураторе.
- После изменений проверять соответствие версии основной конфигурации и расширения.

## Git

Перед коммитом проверять:

```powershell
git status --short
git diff --stat
```

Не добавлять `.env`, токены, логи, виртуальные окружения, базы и сборочные артефакты.
